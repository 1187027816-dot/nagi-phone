# 删除更新公告与关于内容

## 目标

从应用和源码中完整移除以下内容：

- 启动时自动显示的“更新公告”弹窗。
- “关于本机”页面中的“关于弯弯”入口及其正文。
- “关于本机”页面中的“更新日志”入口及全部版本记录。

保留“关于本机”页面及其中的“免责声明”入口和免责声明弹窗。

## 实现范围

### 启动流程

删除启动流程对更新公告的调用，并删除公告内容、版本哈希、本地确认记录、倒计时、弹窗构建和关闭逻辑。既有浏览器中残留的公告确认键无需迁移；它将不再被读取。

### 关于本机

将“关于本机”页面简化为只显示“免责声明”。删除关于弯弯和更新日志的 Markdown 内容、渲染器、通用内容弹窗及事件绑定。

### 样式

更新公告样式目前也被免责声明和关于内容弹窗复用。先把免责声明改为独立的类名和必要样式，再删除全部 `update-notice-*` 样式以及已无用途的关于内容样式，确保源码中不再遗留更新公告命名或死样式。

## 保持不变

- 免责声明的内容、首次确认行为和等待时间。
- “关于本机”页面的打开方式。
- 其他通知、桌面角标和通知面板功能；它们与更新公告无关。

## 验证

- 全项目搜索确认不再出现更新公告、更新日志、关于弯弯及其代码标识。
- 检查 JavaScript 语法。
- 检查免责声明仍能从“关于本机”打开，首次启动时原有免责声明流程不受影响。
- 检查应用启动流程不再创建更新公告弹窗。
